# 🧪 Stewie Lab

> 把踩过的坑，写成实验报告。
> **Code · Debug · Fix · Repeat.** ⌒★

一个有点不正经的个人技术博客。

这里记录前端开发、踩坑、折腾、灵感，以及一些“为什么它又坏了”的瞬间。

🌐 **在线体验：** [stewie.fun](https://stewie.fun?utm_source=chatgpt.com)

---

## ✨ What is this?

我不太想做一个普通的博客。

所以把它做成了一间「实验室」：

* 🔬 每篇文章 = 一次实验
* 📋 假设 → 复现 → 修复 → 沉淀
* 📈 有自己的示波器
* 🎮 技术栈做成装备系统
* 🟢 情绪球会和你互动
* 🌙 支持深色模式
* 🧪 到处藏着一些小彩蛋

**写博客只是表面，折腾才是本体。**

---

## 🧩 Features

### 🏠 首页

实验室风格 Hero + 动态标题 + 示波器。

鼠标移动可以控制波形，点击还能切换不同信号。

### 📚 文章

支持：

* 分类筛选
* 分页
* 搜索
* 阅读进度
* 目录
* 代码复制
* 点赞
* 评论

### 👨‍🔬 About

用 Bento Grid 做成一张“研究员档案”。

技能、兴趣、项目、状态，以及一些奇奇怪怪的小东西，都放在这里。

### 🎮 Arsenal

把技术栈变成 RPG 装备：

> 技术不是列表，是我的装备栏。

### 🤖 Admin

完整的后台管理：

* 文章管理
* Markdown 编辑
* 评论管理
* 作者信息
* 数据统计

## 📁 Structure

```text

├── api/          # API
├── assets/       # 静态资源
├── components/   # 公共组件
├── composables/  # Composables
├── editor/       # Markdown 编辑器
```

## 🎨 Design

整个网站围绕一个简单的想法：

> **如果技术博客本身也是一个实验呢？**

所以你看到的：

**蓝图、坐标线、示波器、实验编号、RPG 属性、漫画、情绪球……**

都不是单纯为了“炫”。

它们共同组成了这个博客的世界观。
